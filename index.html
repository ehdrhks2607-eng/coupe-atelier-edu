기본을 그리다,
섬세함을 가르치다

우리 살롱의 시그니처 시술 철학을 파트너들과 함께 배우는 공간입니다. 용어부터 시그니처 스타일, 컬러 레시피, 그리고 AI와 함께하는 도해 실습까지.

01

기본 용어와 이론

현장에서 가장 자주 쓰이는 핵심 개념들. 도해도를 그리려면 이 용어부터 손에 익어야 합니다.

섹션링
Sectioning
머리 전체를 시술 목적에 따라 구획으로 나누는 작업. 4분할, 9분할 등 시술 종류에 따라 달라지며 모든 시술의 시작점입니다.
엘레베이션
Elevation
모발을 두피에서 들어올리는 각도. 0°(low), 45°(medium), 90°(high)로 구분되며 각도가 클수록 더 많은 레이어가 생깁니다.
레이어
Layer
길이가 다른 모발층을 겹쳐서 볼륨과 움직임을 만드는 기법. 짧은 레이어는 볼륨, 긴 레이어는 자연스러운 흐름을 줍니다.
골든 포인트
Golden Point
정수리 가장 높은 지점. 머리의 균형을 결정하는 핵심 지점으로, 펌·커트 디자인의 기준점이 됩니다.
헤어라인
Hairline
모발이 자라는 경계선. 페이스라인·네이프라인·이어백 등으로 세분화되며, 잔머리 처리와 디자인에 큰 영향을 줍니다.
그래쥬에이션
Graduation
아래는 짧고 위로 갈수록 길어지는 단차 커트. 보브 라인의 무게감과 입체감을 만드는 핵심 기법입니다.
베이스
Base / Sub-section
시술 단위로 잡는 작은 모발 다발. 베이스의 크기와 방향이 컬러 도포·펌의 결과를 좌우합니다.
패러럴 라인
Parallel Line
바닥과 수평이 되는 가이드 라인. 원랭스·블런트 보브의 깔끔한 절단면을 만드는 기준선입니다.
02

시그니처 스타일 도해도

우리 살롱의 대표 스타일 4종. 각 스타일의 섹션 분할, 커트 각도, 마무리 포인트를 도해로 정리했습니다.

SIGNATURE 01
French Bob
턱선 길이0° CutBlunt
  • 4분할 섹션, 백포인트부터 시작
  • 턱끝 라인 기준 패러럴 0° 커트
  • 앞머리 시스루로 자연스러운 갭
  • 안쪽 C컬 셋팅 마무리
SIGNATURE 02
Soft Layered
가슴 길이45° ElevLong
  • 9분할 섹션, 사이드 라이트 추가
  • 중간 길이부터 45° 엘레베이션
  • 레이어 간격 3-4cm 유지
  • 페이스라인 곡선 마감
SIGNATURE 03
Wolf Cut
믹스 길이90° TopEdgy
  • 탑 레이어 90° 들어올려 짧게
  • 네이프는 길게 남겨 콘트라스트
  • 커튼뱅 또는 자연스러운 앞머리
  • 드라이로 볼륨 강조
SIGNATURE 04
Modern Pixie
귀 위 길이TextureShort
  • 탑 7-9cm 길이 유지, 슬라이드 컷
  • 사이드 3-4cm 그래쥬에이션
  • 네이프 클리퍼 또는 가위 짧게
  • 왁스로 자연스러운 흐름
03

컬러·펌 레시피

자주 나가는 인기 시술의 표준 레시피. 정확한 비율과 방치 시간은 일관된 품질의 시작점입니다.

Warm Chestnut
SIGNATURE · WC-001
베이스: 6.3 (다크 골든)
믹스: 6.3 + 7NB = 1 : 1
옥시: 6% (20vol)
도포: 뿌리부터 끝까지 동일량
방치: 35분난이도: 초급
Black Cherry
SIGNATURE · BC-002
베이스: 4.0 (다크 브라운)
믹스: 4.0 + 4.62 = 2 : 1
옥시: 3% (10vol)
도포: 뿌리 우선, 길이부 5분 후
방치: 30분난이도: 중급
Honey Beige
SIGNATURE · HB-003
베이스: 8.31 (라이트 골든 베이지)
믹스: 8.31 + 9.0 = 1 : 1
옥시: 9% (30vol)
도포: 1단계 탈색 후 토너 적용
방치: 탈30·토20난이도: 상급
Cool Mocha
SIGNATURE · CM-004
베이스: 5.1 (라이트 애쉬)
믹스: 5.1 + 6.71 = 1 : 1
옥시: 6% (20vol)
도포: 새치 부위 더블링
방치: 40분난이도: 중급
Natural Wave
PERM · NW-001
롯드: 30mm 메인 + 25mm 사이드
1제: 시스테인 (저자극)
방향: 안말음, 9분할
방치: 1제 15분 → 2제 10분
총: 2.5시간난이도: 초급
Sleek S-Curl
PERM · SC-002
롯드: 35mm 탑 + 30mm 미디엄
1제: 디지털 펌 (가온)
방향: 교차 와인딩 (S컬)
방치: 가온 80°C × 8분
총: 3시간난이도: 상급
Body Volume
PERM · BV-003
롯드: 40mm 메인 전체
1제: 일반 콜드 (#2 약)
방향: 굵은 베이스, 정수리 집중
방치: 1제 20분 → 2제 15분
총: 2시간난이도: 초급
Beach Wave
PERM · BW-004
롯드: 25mm + 20mm 믹스
1제: 시스테인 + 단백질 트리트
방향: 끝부분만 와인딩
방치: 가온 60°C × 12분
총: 2.5시간난이도: 중급

Gemini API 키 설정

AI 분석 기능을 사용하려면 본인의 Google AI Studio API 키가 필요합니다. 무료이고, 신용카드 등록도 필요 없습니다.

중요: 무료 티어는 입력 내용이 Google 모델 학습에 사용될 수 있습니다. 고객 사진은 동의를 받은 경우만 사용하세요.
1
aistudio.google.com/apikey에 접속해 Google 계정으로 로그인
2
"Create API key" 버튼 클릭 → 키가 생성되면 복사
3
아래 입력란에 붙여넣고 저장

API 키는 본인의 브라우저에만 저장되며, 외부로 전송되지 않습니다. (localStorage 사용)
