Gemini API 키 설정

AI 분석을 사용하려면 본인의 Google AI Studio API 키가 필요합니다. 무료이고 신용카드 등록도 필요 없습니다.

주의: 무료 티어는 입력 내용이 Google 모델 학습에 사용될 수 있습니다. 고객 사진은 동의를 받은 경우만 사용하세요.
1
aistudio.google.com/apikey에서 로그인
2
"Create API key" 클릭 → 키 복사
3
아래 입력란에 붙여넣고 저장

키는 본인 브라우저에만 저장되며 외부로 전송되지 않습니다.
