# Coupe Atelier — 헤어 도해도 워크북

미용실 파트너 교육용 **전문가 헤어 도해도** 학습 도구입니다. 6각도 두상 템플릿 위에 직접 그리면서, AI(Gemini)가 분석한 도해도와 비교하며 학습할 수 있습니다.

## 🎯 주요 기능

- **6각도 워크북 레이아웃**: 좌측면, 우측면, 후면, 측면 투시, 정수리, 정면 — 미용 교재 스타일의 전문가용 두상 템플릿
- **그리기 도구 6종**: 섹션(점선), 실선, 화살표, 컬러 영역, 펌 롯드, 텍스트 라벨
- **AI 자동 도해 생성** (Gemini): 사진 분석 → 6개 패널 모두에 섹션 라벨/번호 자동 배치
- **종합 코칭**: 스타일 분석(얼굴형·치수 추정·구조) + 시술 가이드(섹션링·순서·주의사항)
- **AI 표시 모드 전환**: AI만 / 내것만 / 함께 보기
- **PNG 저장**: 완성된 워크북 전체를 이미지로 출력

## 🚀 GitHub Pages 배포 방법

1. GitHub에서 새 저장소 만들기 (예: `coupe-atelier-workbook`)
2. `index.html`과 `README.md`를 저장소 루트에 업로드
3. **Settings → Pages → Source**: `main` 브랜치, `/ (root)` 폴더
4. 1-2분 후 `https://[사용자명].github.io/[저장소명]/` 접속
5. 파트너들에게 링크 공유

## 🔑 Gemini API 키 발급 (각 파트너 1회 설정)

1. [Google AI Studio API 페이지](https://aistudio.google.com/apikey) 접속
2. Google 계정으로 로그인
3. **"Create API key"** 클릭 → 키 복사
4. 사이트 우측 상단 **"API 키 설정"** 클릭 → 키 붙여넣기 → 저장

**비용:**
- 무료 티어 하루 1,500회 분석 (Gemini 2.5 Flash)
- 신용카드 등록 불필요
- 키는 본인 브라우저에만 저장

## 💡 사용 흐름

1. 핀터레스트 또는 다른 곳에서 학습할 헤어 사진 다운로드
2. 사이트 우측 패널에서 사진 업로드
3. **"AI 분석 실행"** 클릭 → 10-20초 후 6개 패널에 가이드 자동 표시
4. 자신이 직접 도구로 같이 그려보면서 비교
5. 하단의 시술 코칭 텍스트로 이론 보강
6. 완성되면 **"PNG 저장"**으로 워크북 출력 → 인쇄 또는 보관

## ⚠️ 주의사항

- 본 사이트에는 어떤 사진도 저장되지 않습니다
- 무료 티어는 입력된 사진을 Google 모델 학습에 사용할 수 있으므로, 실제 고객 사진은 동의를 받은 경우만 사용하세요
- 핀터레스트 등 외부 사진은 본인 개인 학습 목적으로 활용 권장

## ✏️ 커스터마이징

`index.html` 파일을 직접 수정해 살롱 시그니처에 맞게 조정 가능:
- **두상 템플릿**: `const templates = { ... }` 영역의 SVG 패스
- **AI 분석 프롬프트**: `const prompt = ...` 영역에서 분석 방식, 용어, 출력 형식 조정
- **색상 테마**: 최상단 `:root` 변수에서 색상 일괄 변경
