# Coupe Atelier — 파트너 교육 스튜디오

미용실 파트너 교육용 헤어 도해도 학습 도구입니다. **Gemini AI 분석**과 **수동 그리기 비교** 기능이 포함되어 있습니다.

## ✨ 주요 기능

### 가이드 탭
- **기본 용어** — 섹션링, 엘레베이션, 레이어, 골든포인트 등 8개 핵심 용어와 시각 자료
- **시그니처 스타일** — French Bob, Soft Layered, Wolf Cut, Modern Pixie 4개 대표 스타일 도해
- **컬러·펌 레시피** — 시그니처 컬러 4종, 펌 4종의 표준 레시피

### AI 분석 + 실습 탭
- 📸 사진 업로드 (파트너 본인 기기에서만 처리, 외부 저장 안 됨)
- 🤖 **Gemini AI 자동 분석** — 얼굴형·헤어 상태 분석 + 도해도 가이드 라인 자동 생성 + 시술 조언
- ✏️ **수동 그리기** — 섹션·길이·컬러·펌롯드 4가지 도구로 직접 그리기
- ☰ **좌우 비교** — AI가 그린 도해와 내가 그린 도해를 나란히 비교

## 🚀 GitHub Pages 배포 방법

1. GitHub에서 새 저장소 만들기 (예: `coupe-atelier-edu`)
2. `index.html`과 `README.md`를 저장소 루트에 업로드
3. 저장소 **Settings → Pages → Source**를 `main` 브랜치 `/ (root)`로 설정
4. 1~2분 후 `https://[사용자명].github.io/[저장소명]/` 에서 접속 가능
5. 파트너들에게 그 링크 공유

## 🔑 Gemini API 키 발급 (각 파트너가 1회만 설정)

AI 분석 기능을 사용하려면 본인의 무료 API 키가 필요합니다.

1. [Google AI Studio API 페이지](https://aistudio.google.com/apikey) 접속
2. Google 계정으로 로그인
3. **"Create API key"** 클릭 → 키 복사
4. 사이트 우측 상단 **"API 키 설정"** 버튼 클릭 → 키 붙여넣기 → 저장

**비용 안내:**
- 무료 티어: 하루 1,500회 분석 가능 (Gemini 2.5 Flash 모델 기준)
- 신용카드 등록 불필요
- 키는 본인 브라우저(localStorage)에만 저장되며 외부로 전송되지 않음

## ⚠️ 사용 시 주의사항

### 사진 사용에 대해
- **본 사이트에는 어떤 사진도 미리 저장되어 있지 않습니다.**
- 파트너가 실습 시마다 본인이 직접 사진을 업로드합니다.
- 업로드된 사진은 파트너 브라우저 → Gemini API로만 전송되며, 저장되지 않습니다.

### 무료 티어 약관 주의
- Google 무료 티어는 입력된 사진을 모델 학습에 사용할 수 있다는 약관이 있습니다.
- 실제 고객 사진을 사용할 경우 고객 동의를 받으세요.
- 핀터레스트 등 외부 사진은 본인 개인 학습 용도로만 사용 권장.

## ✏️ 콘텐츠 커스터마이징

`index.html` 파일을 직접 수정해 매장 시그니처 콘텐츠로 교체 가능합니다.

- **용어**: `<!-- TERMS -->` 영역 내 `.term-card` 수정
- **시그니처 스타일**: `<!-- STYLES -->` 영역 내 `.style-card` 수정
- **레시피**: `<!-- RECIPES -->` 영역 내 `.recipe-card` 수정
- **AI 프롬프트**: JavaScript 내 `const prompt = ...` 부분에서 분석 방식 조정 가능
