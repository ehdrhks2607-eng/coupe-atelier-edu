# Coupe Atelier — 헤어 도해도 워크북

미용실 파트너 교육용 **전문가 헤어 도해도** 학습 도구입니다. 5각도 두상 일러스트 위에 직접 그리고, Gemini AI가 분석한 커트 각도·길이 가이드를 비교하며 학습할 수 있습니다.

## 🎯 주요 기능

- **5각도 워크북 레이아웃**: 좌측면 · 정면 · 우측면 (상단), 후면 · 정수리 (하단)
- **두상 일러스트 임베드**: 5개의 전문 두상 일러스트가 파일에 포함되어 인터넷 없이도 작동
- **그리기 도구 6종**: 섹션(점선) · 실선 · 화살표 · 컬러 영역 · 펌 롯드 · 텍스트 라벨
- **AI 자동 도해 생성** (Gemini): 사진 분석 → 5개 각도 모두에 **주황색 커트 각도·길이 폴리라인** 자동 표시
- **종합 코칭**: 스타일 분석(얼굴형·헤어 상태) + 시술 가이드(섹션링·순서·주의사항)
- **AI 표시 모드**: AI만 / 내것만 / 함께 보기
- **모바일·태블릿 완벽 호환**: 반응형 레이아웃, 터치 그리기 지원
- **PNG 저장**: 완성된 워크북 전체를 이미지로 출력

## 🚀 GitHub Pages 배포 방법

1. GitHub에서 새 저장소 만들기 (예: `coupe-atelier-workbook`)
2. `index.html`과 `README.md`를 저장소 루트에 업로드
3. **Settings → Pages → Source**: `main` 브랜치, `/ (root)` 폴더
4. 1-2분 후 `https://[사용자명].github.io/[저장소명]/` 접속
5. 파트너들에게 링크 공유

## 🔑 Gemini API 키 발급 (각 파트너 1회 설정)

1. [Google AI Studio API 페이지](https://aistudio.google.com/apikey) 접속
2. Google 계정으로 로그인
3. **"Create API key"** 클릭 → 키 복사
4. 사이트 우측 상단 **"API 키"** 클릭 → 키 붙여넣기 → 저장

**비용:**
- 무료 티어 하루 1,500회 분석 (Gemini 2.5 Flash)
- 신용카드 등록 불필요
- 키는 본인 브라우저에만 저장

## 💡 사용 흐름

1. 핀터레스트 등에서 학습할 헤어 사진 다운로드
2. 사이드 패널에서 사진 업로드 (폰: 우하단 ☰ 버튼)
3. **"AI 분석 실행"** 클릭 → 10-20초 후 5개 패널에 주황 폴리라인 표시
4. 자신이 직접 도구로 같이 그려보면서 비교 학습
5. 하단 코칭 텍스트로 이론 보강
6. **저장** 버튼으로 PNG 출력
